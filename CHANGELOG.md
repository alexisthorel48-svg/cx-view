# Changelog

## [1.0.0] - 2026-07-28

### Ajouté
- Indicateur de stockage du VPS sur le tableau de bord Super Admin.
- Affichage du disque total, de l’espace utilisé, de l’espace disponible et du taux d’occupation.
- Niveau d’alerte visuel selon l’occupation du disque.

### Modifié
- Version officielle de CX View Admin fixée à `1.0.0`.
- Harmonisation des références de version visibles et des paramètres de cache principaux.

### Supprimé
- Ancienne note annonçant de futures commandes du Player Windows dans les paramètres d’écran.

### Sécurité
- Les informations système du VPS sont renvoyées uniquement aux comptes `SUPER_ADMIN`.
